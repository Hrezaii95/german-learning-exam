# Learning Journey and Mastery Model

## The learner’s two complementary paths

### Lesson path

The lesson path preserves the course’s pedagogical sequence and gives a finite daily journey.

1. **Orient** — hero, communicative goal, prerequisite check, source/teacher scope.
2. **See** — original visual overview that locates new concepts spatially.
3. **Hear** — listen without reading, then with highlighted text.
4. **Notice** — gender, stress, ending, word order or contrast is made explicit.
5. **Repeat** — normal/study audio and learner recording.
6. **Recall** — type, choose, arrange or produce without the answer visible.
7. **Use** — complete a phrase, Q&A pair or mini-dialogue.
8. **Check** — mixed checkpoint with corrective explanations.
9. **Review** — weak and due items join the global queue.
10. **Summarize** — two-minute lesson sheet and links into hubs.

The learner may leave and resume at any activity. Skipping is allowed for a personal tool, but skipped stages remain visibly incomplete.

### Hub path

The hub path supports non-linear study after an item is unlocked or deliberately selected.

- **Vocabulary hub:** words/person forms/plurals, semantic collections, morphology filters.
- **Verb hub:** meanings, conjugation families, regular/special/irregular filters.
- **Grammar hub:** visual concepts and prerequisite graph.
- **Phrases & Q&A hub:** communicative intent, register, question pattern and answer slots.
- **Listening hub:** sounds, words, sentences, dialogues and verified workbook exercises.
- **Concept hub:** combines all types for concepts such as Introductions or Professions.

Each hub item shows `Learn`, `Practise`, `Review`, `Source lesson` and `Related` actions. “All” content is available behind an explicit filter; the default view is learned/unlocked content to avoid accidental overload.

## Lessons 1–2 journey

### Onboarding calibration

- choose daily target (10, 15 or 20 minutes);
- explain the grammatical visual code;
- test audio and microphone without scoring;
- offer a short placement/known-items mark, never silently skip official content;
- store interface preferences locally.

### Lesson 1 — introductions

The learner moves from `Hallo` and names to a short complete exchange:

`Guten Tag → Wie heißen Sie? → Mein Name ist … → Woher kommen Sie? → Ich komme aus … → Wie geht’s Ihnen? → Gut, danke. → Auf Wiedersehen.`

The sequence introduces `ich/du/er/sie/Sie`, `sein/heißen/kommen/lernen`, W-question position, statements, `du/Sie`, alphabet/spelling, greetings, wellbeing and countries.

### Lesson 2 — personal profile and profession

The learner expands the exchange with age, residence, relationship status, numbers and work:

`Wie alt sind Sie? → Ich bin … Jahre alt. → Wo wohnen Sie? → Ich wohne in … → Was machen Sie beruflich? → Ich arbeite als … / bei … → Was sind Sie von Beruf? → Ich bin …`

Core lesson professions are learned first. The teacher’s 48-job collection then opens as an assignment/enrichment deck sharing the same morphology, audio and review system.

## Mastery dimensions

Every concept has independent evidence buckets:

| Dimension | Evidence examples | Minimum Alpha state |
|---|---|---|
| Exposure | visual/audio opened | seen/heard timestamps |
| Recognition | choose image/meaning/article after cue | recent correct/total and latency |
| Recall | type/say German from meaning/image | normalized answer result |
| Listening | identify or transcribe from audio | track/speed and result |
| Form | article, plural, conjugation, word order | rule-specific result |
| Production | build/use in a sentence or Q&A | rubric result; recording may be self-rated in Alpha |
| Stability | successful recall over spaced intervals | scheduler state and review history |

Status is derived, never directly toggled by UI:

- **New:** no meaningful attempt.
- **Exploring:** exposed but insufficient retrieval evidence.
- **Learning:** successful guided work or unstable recall.
- **Practising:** recall is successful but not yet stable across time/modalities.
- **Strong:** multiple dimensions meet threshold and delayed recall exists.
- **Mastered:** required dimensions and spaced checkpoints are satisfied.

For Alpha, speech recording counts as production practice only when the learner completes listen→record→playback→self-check. It cannot satisfy pronunciation accuracy until validated assessment exists.

## Feedback rules

1. State whether the answer is correct, partly correct or incorrect.
2. Point to the smallest actionable contrast: article, umlaut, ending, verb position, register, stress.
3. Replay or reveal only the relevant help.
4. Offer immediate retry.
5. Log the error tag so related items can enter a focused mission.

Incorrect feedback must never be only red color or “Try again.”

## Unlocking

- Lesson 1 and Lesson 2 are directly selectable.
- Entering Lesson 2 without Lesson 1 shows prerequisite recommendations but does not hard-block the learner.
- A concept becomes `unlocked` when introduced in a selected lesson or explicitly added by the learner.
- Teacher extras become unlocked when their assignment collection is opened.
- Review includes only unlocked content.

## Daily mission

A default 15-minute mission contains:

- 35% due recall cards;
- 20% listening discrimination/transcription;
- 15% form practice (articles, plurals, conjugation, word order);
- 15% difficult/tagged items;
- 10% phrase/Q&A production;
- 5% one older mixed challenge.

The ratios are targets, not a reason to invent unavailable task types. The mission explains why each set is included and can be filtered to “Only difficult,” “Teacher assignment,” or one lesson.

## Gamification boundary

XP is awarded for first meaningful attempts, correct retrieval, correcting an error, completing a recording cycle and returning for spaced review. Replaying audio repeatedly without a task, opening cards, or guessing rapidly does not farm mastery or large XP.
