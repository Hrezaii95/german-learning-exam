# Six-sheet learning release

## Outcome
Ship the six connected cheat sheets and a usable phone navigation system to the existing GitHub Pages site. The countries and home sheets were verified live before work on the four additional sheets began.

## Release sequence
1. Retain the country flags, selected-country world map, article chart, original recordings, dictionary, selection lookup and saved review.
2. Add the all-30 home overview, grouped by grammatical gender with illustrations and plurals.
3. Add People, family & work: generation chart, profession pairs, possessives, 64 source cards.
4. Add Verbs & sentences: 21 complete present-tense patterns, person selector, word-order and negation diagrams, 99 source cards.
5. Add Numbers & prices: interactive number composition, price and digit reading, number ladder, 104 source cards.
6. Add Conversation & spelling: du/Sie conversation switch, question-and-answer overview, help phrases, alphabet, 47 source cards.
7. Replace the phone Hubs bar with Book, Lessons, Cheat sheets, My review and a complete menu. Add the six-sheet phone switcher.
8. Run content, audio-hash, type, accessibility-lint, unit, export and browser checks. Inspect phone and desktop renders. Commit the exact release files and push codex/live-alpha.
9. Verify the successful deployment and the actual live interactions before closing the goal.

## Learning conventions
Gender retains the vocabulary-card semantic colors and explicit article labels. Purple in number/verb diagrams represents the labelled pattern, not noun gender. Each source card retains its existing saved-review identity. Author-created practice details are fictional and are identified as examples. Existing source audio is reused; new exact-text recordings use German synthesized speech. Dynamic user-entered numbers use browser speech when no matching recording exists.
